03a

Agent 术语 & Skill 体系

📖 核心术语速查

术语英文解释类比
技能Skill注入 Agent 的领域知识和指令（SKILL.md 文件）员工的"操作手册"
工具ToolAgent 可调用的函数（搜索、读文件、调 API）员工的"工具箱"
MCPModel Context ProtocolAgent 连接外部数据/工具的标准化协议"USB-C 接口"
A2AAgent-to-AgentAgent 之间互相通信的 HTTP 协议"Agent 的 HTTP"
上下文ContextAgent 当前能"看到"的所有信息"工作台面"
RAGRetrieval-Augmented Generation检索增强生成：先检索相关文档，再让 LLM 生成回答"开卷考试"
Guardrails安全护栏限制 Agent 行为的安全边界"安全围栏"
沙箱Sandbox隔离的安全执行环境"安全实验室"
记忆MemoryAgent 的长期/短期记忆存储"笔记本"
规划PlanningAgent 将复杂任务拆解为子步骤的能力"做计划"
反思ReflectionAgent 审视自身输出并改进的能力"自我检查"
Function Calling函数调用LLM 输出结构化 JSON 来调用外部函数"下指令"

🎯 Skill vs Tool：关键区别

📝 Skill（技能）

  • 注入 Agent 的指令和知识
  • 告诉 Agent "怎么做"
  • SKILL.md 文件定义
  • 例：代码审查规范、写作风格指南
+

🔧 Tool（工具）

  • Agent 可调用的函数
  • 让 Agent "能做什么"
  • 代码定义，有输入输出
  • 例：搜索、读文件、调 API

公式：Agent = LLM + Skills（专业知识） + Tools（执行能力） + Memory + Planning

📂 Skill 目录结构 & 示例 
skills/
└── code-review/
    ├── SKILL.md          # 必须 — 前置元数据 + 指令
    ├── references/       # 可选 — 参考文档
    │   └── style-guide.md
    └── scripts/          # 可选 — 可执行脚本
---
name: code-review
description: 代码审查的安全和性能检查清单
---

## 审查清单
1. **安全**：检查注入漏洞、认证绕过
2. **性能**：检查 N+1 查询、阻塞调用
3. **可读性**：命名清晰、注释适当
4. **测试**：新功能是否有测试覆盖

用 Cursor 从零搭建「AI 简历生成器」全栈 App

真实案例 · 全流程

以下是在 Cursor 中用 Vibe Coding 搭建一个「AI 简历生成器」的完整流程。用户输入个人信息，AI 自动生成专业简历 PDF。全程约 40 分钟。

0

环境准备（5 分钟）

# 1. 下载安装 Cursor（cursor.com）
# 2. 打开 Cursor → 新建窗口 → Open Folder
# 3. 选择一个空文件夹，如 ~/ai-resume-builder
# 4. 打开 Cursor Chat（右下角 Chat 图标 或 Cmd+L）
# 5. 选择模型：Claude Opus 4.8 或 GPT-5.5
#
# ✅ 环境就绪，开始 Vibe Coding！
1

描述需求 → AI 生成项目骨架

# 在 Cursor Chat 中输入（注意结构化）：

## 项目：AI 简历生成器
## 技术栈：Next.js 14 + TypeScript + Tailwind CSS
## 数据库：SQLite（via better-sqlite3）
## AI：OpenAI API（GPT-5.5 生成简历内容）

## 功能需求：
1. 表单页：用户填写姓名、联系方式、教育背景、
   工作经历、技能、项目经验
2. 预览页：实时预览简历排版（支持 3 种模板）
3. 导出页：一键导出为 PDF（使用 @react-pdf/renderer）
4. AI 优化：点击"AI 优化"按钮，GPT 自动润色每段描述

## UI 要求：
- 深色主题，渐变色卡片
- 响应式（桌面 + 移动端）
- 表单分步填写（Step 1/2/3）

请先创建项目结构（package.json、目录结构），
然后实现表单页。
2

审查 + 接受 → 安装依赖

# 打开浏览器访问 localhost:3000

迭代开发 → 逐个功能实现

# ⚠️ 关键原则：每次只做一个功能！

# 第 2 轮对话：
"实现表单的分步填写功能，
 Step 1：基本信息（姓名、电话、邮箱、求职意向）
 Step 2：工作经历（公司、职位、时间段、工作描述）
 Step 3：技能和项目
 每步有上一步/下一步按钮，进度条显示当前步骤"

# 第 3 轮对话：
"实现简历预览页，

    描述，使其更量化、更有影响力、更专业"
