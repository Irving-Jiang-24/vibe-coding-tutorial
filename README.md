# ⚡ Vibe Coding 速通教程

> 5 分钟理解总体，10 分钟深入细节

极简交互式 Vibe Coding 教程，零依赖纯前端，浏览器直接打开 `index.html` 即可。

## 🚀 快速开始

```bash
双击 index.html
# 或本地服务器
python -m http.server 8080
```

## 📤 分享给他人

| 方式 | 操作 |
|------|------|
| **压缩包** | 右键文件夹 → 发送到 → 压缩文件夹，发送 zip 即可 |
| **局域网共享** | 右键运行 `share.ps1`，把终端显示的链接发给同事 |
| **远程下载** | 让对方右键运行 `download.ps1`（需先上传到 GitHub） |
